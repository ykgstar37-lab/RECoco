# 영수증 템플릿 SVG (테마 꾸미기용)

앱의 기본 양식을 샘플 기록으로 뽑은 파일입니다. 다시 뽑기: `design/tools` 에서 `npm run svg`

| 파일 | 양식 | 크기(px, 가로 × 세로) |
|---|---|---|
| 독서_영수증 / 독서_영수증_긴글 | 독서 (도서 위치 안내) | 632 × 1756 / 1824 |
| 영화_티켓 / 영화_티켓_흰색 | 영화 입장권 (분홍·흰 종이) | 672 × 1314 |
| 소비_영수증 | 소비 | 672 × 1386 |
| 여행_사진0장 ~ 4장 | 여행 탑승권 (사진 장수별 배치) | 1146 × 716 (0장) / 1457 |
| 인생네컷_1x4스트립·QR완성본·뒤_스트립 | 네컷 세로 스트립 앞/뒤 | 432 × 1246 |
| 인생네컷_2x2_* · 뒤_2x2 | 네컷 2×2 앞/뒤 | 632 × 806 |
| 인생네컷_가로2x2_블랙 · 뒤_가로 | 네컷 가로 앞/뒤 | 932 × 646 |

크기에는 그림자용 바깥 여백(16~18px)이 포함돼 있어요.

## 열기 전에

- 글자는 윤곽선이 아니라 `<text>` 로 들어 있어요. 아래 무료 글꼴을 깔면 똑같이 보여요 (Google Fonts):
  나눔고딕(NanumGothic, ExtraBold), 나눔고딕코딩, 나눔명조, 나눔손글씨 펜, Space Mono
- 종이 주름·감열지 얼룩은 PNG 이미지로 박혀 있어요. 테마에서 빼거나 바꿔도 돼요.

## 꾸밀 때

- 글자는 **샘플 값**이에요. 실제로는 기록 내용이 들어가고, 제목·남긴 문장이 길면 그 구간 아래가 늘어나요.
- 바꿔도 되는 것: 종이 색·모양(톱니, 홈), 헤더 그림·로고 자리, 선·테두리 스타일, 장식, 글꼴, 색
- 되도록 지킬 것: 들어가는 정보의 종류(제목·날짜·장소 등)와 대략의 순서, 가로 폭
- 실제 가게·극장 브랜드(CGV, 교보문고 등)를 흉내 내지 말고 가상의 브랜드로

## 돌려줄 때

- SVG 그대로 + PNG 미리보기 한 장
- 글자는 윤곽선으로 바꾸지 말고 `<text>` 로 두기. 레이어 이름에 무엇인지 적어주면 좋아요 (예: `제목`, `날짜`, `장소`)
- 받은 디자인은 앱 코드(템플릿 .tsx)로 옮겨서 "영수증 테마"로 넣어요
