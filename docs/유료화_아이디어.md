# 유료화 아이디어 (메모)

## 확정 (2026-09-17)

- 기존 5개 카테고리(독서·영화·소비·여행·인생네컷)는 **계속 무료**. **새 카테고리**만 유료
- **개별 구매 + 전부 묶음 할인**: 새 카테고리 1,500원(안) · 코코 모자 1,000원 · 전부 해금 4,400원 (만원 넘기지 않기)
- **코코 옷**: 일부는 기록 보상으로 해금 (리본 3장 · 비니 10장 · 밀짚모자 30장), 나머지 유료 (베레모 · 왕관 · 파티 고깔 · 헤드폰)
- 구현: `app/src/lib/shop.ts` (상품·해금 규칙·저장), `components/Closet.tsx` (옷장), `components/Outfits.tsx` (모자 그림)
- 실제 결제는 아직 연결 안 함: 개발 모드에선 바로 구매 처리, 출시 빌드에선 "결제는 스토어 출시 버전에서 열려요"
  → 개발 빌드 + App Store Connect / Google Play Console 상품 등록 + RevenueCat(또는 expo-iap) 연결, 구매 복원 버튼 필요

- **영수증 테마(유료, 예정)**: 같은 기록을 다른 종이·양식으로 뽑기 (예: 빈티지 극장표, 헌책방 영수증). 상점에 '곧 나와요'로 자리만 잡아둠
- 메인 점 세 개 메뉴 → 상점 · 코코 옷장 · 설정. 설정에 진동 끄기, 구매 복원, 저장 위치 안내, 데이터 출처(TMDB 표기)

아래는 처음 정리했던 메모.

> 2026-09-17 정리. 아직 구현하지 않음. 우선순위는 공유·수정·입력 편의 기능 이후.

## 원칙

기록하는 것 자체는 **무료**로 두고, **더 예쁘게 · 더 오래 · 더 많이 자랑하는 것**에 돈을 받는다.
기록 개수 제한이나 QR 가져오기 제한은 하지 않는다 (쌓기 전에 떠남).

## 무료

- 5가지 기록(독서·영화·소비·여행·인생네컷) 전부, 개수 무제한
- 기본 양식 · 기본 프레임
- QR 가져오기, 기기 저장
- 이미지로 저장 (구석에 작은 `레코코` 워터마크 → 공유될 때마다 홍보)

## 유료 후보

| 기능 | 왜 돈을 낼까 | 형태 |
|---|---|---|
| 양식 스킨 팩 (빈티지 극장표, 아이맥스 티켓, 헌책방 영수증, 네컷 프레임 등) | 모으는 재미, 꾸미기 | 팩별 단건 |
| 워터마크 없는 고화질 저장·공유 | 인스타에 깔끔하게 | 구독 |
| 클라우드 백업·기기 간 동기화 | 폰 바꿔도 추억 유지 (사진 저장 비용 발생) | 구독 |
| 연말 결산 영수증 ("올해 읽은 책 23권, 본 영화 14편…") | 연말 공유 콘텐츠 | 구독 (일부 무료 맛보기) |
| 내 이름 넣기 (헤더를 "코코문고"처럼, 손글씨 폰트 선택) | 나만의 기록장 | 구독 또는 단건 |
| 실물 인쇄 주문 (영수증 롤, 네컷 앨범) | 손에 쥐는 추억 | 추후 제휴 |

## 가격 구성 (안)

- **레코코 플러스** 구독: 월 2,900원 / 연 19,900원 — 백업, 워터마크 제거, 전체 스킨, 연말 결산
- 스킨 팩 단건: 1,200~2,500원
- 평생 이용권(선택): 39,000원 선
- ※ 감으로 잡은 가격. 출시 전 비슷한 국내 기록 앱 시세 확인할 것
