# 레코코 로드맵 (정해둔 것, 아직 안 만든 것)

## 입력 편의

### 캡처에서 글자 읽기 — 만드는 중
- 폰 안 ML Kit(한국어)로 캡처 속 글자를 읽어, 이미 있는 문자 규칙(`lib/cardSms.ts`, `lib/movieSms.ts`)에 넣는다
- 코드는 들어가 있음 (`lib/ocr.native.ts`, 붙여넣기 화면의 "캡처에서 읽기"). **개발 빌드에서 실제 캡처로 확인 필요** → `docs/개발빌드_만들기.md`
- 이어서: 선물 교환권 캡처(상품명·브랜드·보낸 사람·유효기간), 종이 영수증 사진(품목·합계)

### 안드로이드: 결제 알림 자동으로 가져오기 — 안드로이드 출시 때
- 카드사 앱 결제 알림은 문자가 아니라 **앱 푸시**라 붙여넣기가 안 됨. 아이폰은 다른 앱 알림을 읽을 수 없어서 캡처 방식으로만.
- 안드로이드는 사용자가 "알림 접근" 권한을 주면 `NotificationListenerService` 로 알림 글자를 받을 수 있음
  - 카드사 앱(신한·삼성·국민·현대·롯데·하나·우리·NH·토스·카카오뱅크 등) 패키지 알림만 골라서
  - `parseCardSms` 로 읽고 → "달밤커피 12,500원 기록할까요?" 알림/앱 안 목록 → 누르면 소비 폼이 채워진 채로 열림
- 필요한 것: 개발 빌드, 알림 접근 권한 안내 화면, 네이티브 모듈(직접 작성 또는 라이브러리), 개인정보 처리방침에 "결제 알림 글자를 기기 안에서만 읽음" 명시
- 구글 플레이 정책: 알림 접근 권한은 핵심 기능 설명이 필요 (심사 대비 문구 준비)

### 그 밖에
- 소비: 총액만 적기 모드, 자주 가는 가게 자동완성 — **만듦**(2026-09-18, 카페·맛집 가게 이름에도 같이)
- 영수증 사진 AI 인식(더 정확, 유료 기능 후보)

## 새 카테고리 (개별 유료)
- 만듦: 선물(교환권), 카페·맛집(맛집 주문서 — 메뉴별 별점·포스트잇 후기·또 갈래요, 결제 문자로 가게·날짜·금액 채우기)
- 공연·전시: 만듦(kind show — 뮤지컬·연극/전시 종류별 색 입장권)
- 콘서트: 따로 만듦(kind concert — 밤하늘 티켓·흰 무지 기본 + 유료 테마: 레트로 티켓, 팔찌 티켓, 포토 티켓, 별빛 티켓)
- 남음: 운동, 음악 (상점에 "준비 중"으로만 안내)
- 카페·맛집 다음 편의 후보: 가게 검색(카카오 로컬, 카카오맵 사용 설정 필요)으로 위치 자동
