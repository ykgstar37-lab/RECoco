# 개발 빌드 만들기 (Expo Go 대신 레코코 전용 앱)

캡처 속 글자 읽기(ML Kit), 인앱 결제, 안드로이드 알림 읽기처럼 **네이티브 모듈**이 들어간 기능은 Expo Go 에서 안 돌아가요.
레코코 전용 "개발 빌드" 앱을 폰에 한 번 설치하면, 이후 코드 수정은 지금처럼 `npx expo start` 로 바로 반영돼요.
(네이티브 모듈을 새로 추가할 때만 다시 빌드)

> **개발 빌드를 설치하기 전까지 Expo Go 로 볼 때는** `npx expo start --go` 로 켜세요. (expo-dev-client 가 들어가서 그냥 `npx expo start` 는 개발 빌드용 QR 을 띄워요)

앱 ID: `com.yoongyeongeun.recoco` (app.json). **스토어에 처음 올리기 전까지만** 바꿀 수 있어요.

## 준비 (한 번만)

```
npm install -g eas-cli
eas login            # Expo 계정 yoongyeongeun
cd C:\dev\RECoco\app
eas init             # 프로젝트 연결 (app.json 에 projectId 가 추가됨)
```

## 안드로이드 (계정 비용 없음)

```
eas build --profile development --platform android
```
빌드가 끝나면 나오는 링크/QR 로 APK 를 폰에 설치 → `npx expo start` 후 앱에서 서버 연결.

## 아이폰 (Apple Developer Program 필요, 연 $99)

아이폰에는 애플 개발자 계정 없이 직접 만든 앱을 설치할 수 없어요. 스토어 출시에도 어차피 필요해요.

```
eas device:create                                  # 내 아이폰 등록 (안내 링크를 폰으로 열기)
eas build --profile development --platform ios
```
빌드 링크를 아이폰에서 열어 설치 → 설정 > 개인정보 보호 및 보안 > 개발자 모드 켜기 → `npx expo start` 후 연결.

빌드는 Expo 서버(클라우드)에서 돼서 윈도우 PC 로도 아이폰 앱을 만들 수 있어요. 무료 요금제는 한 달 빌드 횟수 제한이 있어요.

## 개발 빌드에서 확인할 것

- 소비·영화 "문자·캡처로 채우기" → **캡처에서 읽기** (결제 알림·이용내역·예매 내역 캡처)
- 책 바코드, 탑승권 바코드, 교환권 바코드 카메라
- 공유·앨범 저장, 백업 파일 만들기/불러오기
