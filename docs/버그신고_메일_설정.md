# 버그 신고를 메일로 받기 (구글 Apps Script)

앱의 **설정 > 버그 신고하기**에서 보낸 내용과 스크린샷이 `yge0307@gmail.com` 으로 메일로 도착하게 합니다.
서버·유료 서비스 없이, 받을 구글 계정에서 한 번만 설정하면 돼요. (하루 최대 100통, 첨부 합계 25MB)

## 1. 스크립트 만들기

1. 받을 구글 계정(yge0307@gmail.com)으로 로그인한 뒤 https://script.google.com 접속
2. **새 프로젝트** → 이름을 `레코코 버그 신고`로
3. 기본 코드(`function myFunction...`)를 모두 지우고 아래 코드를 붙여넣기
4. `KEY` 값을 `app/.env.local` 의 `EXPO_PUBLIC_REPORT_KEY` 값으로 바꾸기
5. 저장(Ctrl+S)

아래 회색 칸 **안의 코드만** 복사하세요 (첫 줄은 `const TO` 로 시작해야 해요).

```
const TO = 'yge0307@gmail.com';
const KEY = '여기에_EXPO_PUBLIC_REPORT_KEY_값';

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    if (data.key !== KEY) return json({ ok: false, error: 'key' });

    const attachments = (data.photos || []).slice(0, 3).map((p, i) =>
      Utilities.newBlob(Utilities.base64Decode(p.base64), p.mime || 'image/jpeg', p.name || 'screenshot-' + (i + 1) + '.jpg'),
    );
    const contact = /^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(data.contact || '') ? data.contact : '';

    MailApp.sendEmail({
      to: TO,
      subject: '[레코코 버그 신고] ' + (data.type || '기타'),
      body: [
        data.detail || '(내용 없음)',
        '',
        '---',
        '답장 받을 이메일: ' + (contact || '(없음)'),
        '앱 버전: ' + data.version,
        '기기: ' + data.device,
        '모은 영수증: ' + data.recordCount + '장',
        '보낸 시각: ' + new Date().toLocaleString('ko-KR', { timeZone: 'Asia/Seoul' }),
      ].join('\n'),
      attachments: attachments,
      replyTo: contact || undefined,
      name: '레코코 버그 신고',
    });
    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}
```

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설명: `버그 신고` / **실행 계정: 나** / **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** → 권한 검토 → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동** → **허용**
   (내가 만든 스크립트가 내 Gmail 로 메일을 보내는 권한이라 괜찮아요)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 복사

## 3. 앱에 연결

`app/.env.local` 에 붙여넣기:

```
EXPO_PUBLIC_REPORT_URL=https://script.google.com/macros/s/.../exec
```

개발 서버를 껐다 켜면 적용돼요. 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 해야 반영돼요 (URL은 그대로).
