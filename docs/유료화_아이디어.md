# 유료화 (현황 · 2026-09-19)

## 원칙

기록하는 것 자체는 **무료**로 두고, **더 예쁘게 · 더 많이 자랑하는 것**에 돈을 받는다.
기록 개수 제한이나 QR 가져오기 제한은 하지 않는다 (쌓기 전에 떠난다).
**개별 구매만** 판다. 구독·전부 해금 묶음은 하지 않기로 했다 (2026-09-17 결정).

## 무료

- 기본 5가지 기록(독서·영화·소비·여행·인생네컷), 개수 무제한
- 기본 양식 · 기본 프레임 · QR 가져오기 · 기기 저장 · 이미지로 저장
- 산 카테고리의 기본 영수증 모양 (카페·맛집 주문서 4색, 공연 흰 무지/포스터 입장권, 콘서트 흰 무지/밤하늘 티켓)
- 소비·인생네컷의 기본 종이와 **흰 무지**
- 기록 보상 옷: 리본(3장) · 하트 꼬랑지(10장) · 밀짚모자(30장)

### 색 고르기 (2026-09-19)

**모양을 먼저 고르고, 그 아래 동그라미로 색을 고른다.** 모양 하나가 여러 색을 갖는 구조라, 색은 따로 팔지 않는다.

| 모양 | 색 |
|---|---|
| 주문서 (무료) | 초록 · 먹색 · 남색 · 팥색 |
| 집 모양 | 주황 · 빨강 · 분홍 · 파랑 · 초록 (고를 때 무작위로 하나 정해준다) |
| 모눈종이 | 연두 · 하늘 · 분홍 · 회색 |
| 팔찌 티켓 | 검정(라임 글씨) · 주황 · 흰색 · 남색 · 분홍 · 하늘 — 끈 바탕색이 바뀐다 |
| 포토 티켓 | 분홍 · 하늘 · 버터 · 민트 |
| 별빛 티켓 | 파랑 · 보라 · 청록 · 와인 · 검정 (예전 이름 홀로그램 기록표. 무지개 띠는 2026-09-19 에 뺐다) |
| 레트로 티켓 | 남색 · 숲 초록 · 버건디 · 세피아 · 먹색 (크림 종이는 그대로, 조각·포인트만 바뀜) |

- 상점 미리보기에 색마다 한 장씩 보여준다 (두 카테고리가 같이 쓰는 모양은 콘서트·공연을 번갈아)
- 콘서트 레트로처럼 **가로로 납작한 모양**은 한 칸에 여러 색을 세로로 쌓아 보여준다 (`PreviewSample.more`). 쌓은 칸은 옆 칸과 높이가 같아지도록 남는 자리를 장 사이에 나눠 넣는다
- 집 모양의 창문 그림(☕🍚🍰🍺)만 가게 종류를 따른다. 나머지는 색과 무관
- **흰 무지**는 팔지 않고 기본으로 준다 (2026-09-19 변경). 예전 '단색 주문서'는 주문서 먹색으로 합쳤다

## 코드 위치

- `app/src/lib/shop.ts` — 상품 목록, 해금 규칙, 저장(AsyncStorage), 앱 전체가 보는 구매 상태
- 색 팔레트는 각 템플릿 파일에 있다 (`FoodOrder`/`FoodHouse`/`WristBand`/`PhotoTicket`/`ShowHolo`/`shared`의 `GRID_COLORS`)
- `app/src/lib/billing.native.ts` — 스토어 결제 (expo-iap 5.6.2). `billing.ts` 는 웹용 빈 껍데기
- `app/src/lib/products.ts` — 상점 미리보기용 상품 설명
- `app/src/components/Shop.tsx` — 상점 화면 · `Closet.tsx` 옷장 · `Outfits.tsx` 모자 그림 · `ThemePicker.tsx` 테마 고르기
- 메인 점 세 개 메뉴 → 상점 · 코코 옷장 · 설정

### 결제 동작

- 전부 **비소모성 1회 구매**. 소비하지 않고 확인만 하므로 "뭘 샀나"는 스토어가 기억한다
- 켤 때 `initShop()` → `startBilling()` 으로 끝나지 않은 거래·다른 기기에서 산 것을 받아온다
- `finishTransaction` 필수 (안 하면 iOS 는 켤 때마다 다시 들고 오고 안드로이드는 3일 뒤 자동 환불)
- **구매 복원** 버튼: 상점 하단 · 설정 양쪽에 있음
- 백업 파일에는 구매 내역을 넣지 않는다 (스토어 복원으로 받는다)
- 개발 모드(`__DEV__`)에선 스토어에 상품이 없어도 눌러서 확인할 수 있게 열어준다. 단 **사용자 취소는 구분해서 해금하지 않는다**
- 웹/Expo Go 에선 결제 불가 → 출시 빌드에서 "결제는 스토어 출시 버전에서 열려요"
