# 개발 빌드 만들기 (Expo Go 대신 레코코 전용 앱)

캡처 속 글자 읽기(ML Kit), 인앱 결제, 안드로이드 알림 읽기처럼 **네이티브 모듈**이 들어간 기능은 Expo Go 에서 안 돌아가요.
레코코 전용 "개발 빌드" 앱을 폰에 한 번 설치하면, 이후 코드 수정은 지금처럼 `npx expo start` 로 바로 반영돼요.
(네이티브 모듈을 새로 추가할 때만 다시 빌드)

> **개발 빌드를 설치하기 전까지 Expo Go 로 볼 때는** `npx expo start --go` 로 켜세요. (expo-dev-client 가 들어가서 그냥 `npx expo start` 는 개발 빌드용 QR 을 띄워요)

앱 ID: `com.yoongyeongeun.recoco` (app.json). **스토어에 처음 올리기 전까지만** 바꿀 수 있어요.

## 지금 상태 (2026-09-18)

- eas-cli 21.7 설치됨, Expo 계정 `yoongyeongeun` 으로 로그인돼 있음
- `eas.json` 에 development 프로필 있음 (developmentClient, internal 배포)
- Apple Developer Program 가입돼 있음 (사용자 확인)
- 아직 안 한 것: `eas init`(projectId 없음), 아이폰 기기 등록, 첫 빌드

## 아이폰 개발 빌드 (직접 실행해야 하는 순서)

애플 로그인이 필요해서 사용자가 직접 터미널에서 실행해요. `C:\dev\RECoco\app` 에서:

```
npx eas init          # Expo 프로젝트 만들고 app.json 에 projectId 추가 (한 번만)
npx eas device:create # 아이폰 등록: "Website" 선택 → 나오는 링크/QR 을 아이폰에서 열어 프로필 설치
npx eas build --profile development --platform ios
```

- `device:create` 와 `build` 에서 **Apple ID 로그인**을 물어봐요. 2단계 인증 코드도 폰으로 와요.
- 인증서·프로비저닝 프로필은 EAS 가 알아서 만들어요 ("Generate new..." 로 그냥 진행).
- 빌드는 Expo 클라우드에서 15~30분쯤 걸려요. 무료 요금제는 한 달 빌드 횟수 제한이 있어요.
- 끝나면 나오는 링크를 **아이폰에서** 열어 설치 → 설정 > 개인정보 보호 및 보안 > **개발자 모드 켜기** → 재부팅.
- 그다음부터: `cd C:\dev\RECoco\app` → `npx expo start` → 레코코 앱에서 서버에 연결.

## 안드로이드 (계정 비용 없음, 나중에)

```
npx eas build --profile development --platform android
```
끝나면 나오는 링크/QR 로 APK 설치 → `npx expo start` 후 앱에서 연결.

## 개발 빌드에서 확인할 것

- 소비·영화·카페맛집 "결제 문자·알림으로 채우기" → **캡처 고르기**(캡처에서 글자 읽기)
  - ⚠️ `@react-native-ml-kit/text-recognition` 은 New Architecture(RN 0.86 기본)에서 검증되지 않은 라이브러리예요. 개발 빌드에서 안 되면 대안을 찾아야 해요.
- 붙여넣기 카드(expo-clipboard) — 아이폰에서 처음 누르면 "붙여넣기 허용" 확인이 떠요
- 책 바코드, 탑승권 바코드, 교환권 바코드 카메라
- 공유·앨범 저장, 백업 파일 만들기/불러오기
- 결제: 지금은 개발 모드에서 바로 구매 처리됨 → 실제 스토어 결제 연결(RevenueCat 또는 expo-iap)은 개발 빌드가 있어야 붙일 수 있어요
