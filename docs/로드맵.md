# 레코코 로드맵 (정해둔 것, 아직 안 만든 것)

## 입력 편의

### 캡처에서 글자 읽기 — 만드는 중
- 폰 안 ML Kit(한국어)로 캡처 속 글자를 읽어, 이미 있는 문자 규칙(`lib/cardSms.ts`, `lib/movieSms.ts`)에 넣는다
- 코드는 들어가 있음 (`lib/ocr.native.ts`, 붙여넣기 화면의 "캡처에서 읽기"). **개발 빌드에서 실제 캡처로 확인 필요** → `docs/개발빌드_만들기.md`
- 이어서: 선물 교환권 캡처(상품명·브랜드·보낸 사람·유효기간), 종이 영수증 사진(품목·합계)

### 안드로이드: 결제 알림 자동으로 가져오기 — 안드로이드 출시 때
- 카드사 앱 결제 알림은 문자가 아니라 **앱 푸시**라 붙여넣기가 안 됨. 아이폰은 다른 앱 알림을 읽을 수 없어서 캡처 방식으로만.
- 안드로이드는 사용자가 "알림 접근" 권한을 주면 `NotificationListenerService` 로 알림 글자를 받을 수 있음
  - 카드사 앱(신한·삼성·국민·현대·롯데·하나·우리·NH·토스·카카오뱅크 등) 패키지 알림만 골라서
  - `parseCardSms` 로 읽고 → "달밤커피 12,500원 기록할까요?" 알림/앱 안 목록 → 누르면 소비 폼이 채워진 채로 열림
- 필요한 것: 개발 빌드, 알림 접근 권한 안내 화면, 네이티브 모듈(직접 작성 또는 라이브러리), 개인정보 처리방침에 "결제 알림 글자를 기기 안에서만 읽음" 명시
- 구글 플레이 정책: 알림 접근 권한은 핵심 기능 설명이 필요 (심사 대비 문구 준비)

### 그 밖에
- 소비: 총액만 적기 모드, 자주 가는 가게 자동완성 — **만듦**(2026-09-18, 카페·맛집 가게 이름에도 같이)
- 영수증 사진 AI 인식(더 정확, 유료 기능 후보)

### 운동: 애플 건강 · Health Connect 연동 — 하기로 함 (2026-09-19)

**왜**: 러닝하는 사람들이 나이키 런 클럽·스트라바로 이미 기록을 남긴다. 레코코에 숫자를 또 적게 하지 말고 가져오자.

**나이키와 직접 연동은 불가능하다.** 나이키 런 클럽은 외부 앱이 쓸 공개 API가 없다(예전 것도 닫힘). 대신 **애플 건강(HealthKit)** 과 **Health Connect(안드로이드)** 가 공용 선반 역할을 해서, 나이키·스트라바·애플워치·삼성헬스가 여기에 올려둔 것을 읽으면 된다. 읽기 전용.

**가져올 것**
- 거리 · 시간 · 페이스 · 활동 에너지(칼로리) · 심박
- **경로 GPS 좌표**(`HKWorkoutRoute`) → 뛴 코스를 영수증에 그림으로 그린다. 이게 이 기능의 핵심 재미
- 칼로리 칸이 지금 운동 폼에 없다 → 같이 추가할 것

**만들 것**
- 폼에 "건강에서 가져오기" → 최근 운동 목록 → 고르면 칸이 채워지고 경로 그림이 붙는다
- `ExerciseRecord` 에 `calories`, `route`(좌표 배열 또는 그려둔 path) 추가
- 경로를 SVG path 로 줄여 저장(좌표 수백 개를 그대로 들고 있지 않게)

**주의**
- 네이티브 모듈이라 **개발 빌드 필요**. iOS 는 Info.plist 에 건강 데이터 사용 목적, 심사 때 설명 필요(읽기 전용이라 비교적 수월)
- 안드로이드는 Health Connect 로 **따로 한 번 더** 붙여야 한다
- **나이키 런 클럽은 사용자가 '건강에 쓰기'를 켜야** 데이터가 들어간다. 안 켠 사람은 비어 보이므로 안내 문구 필요
- 웨이트(헬스)의 칼로리는 추정치라 러닝만큼 정확하지 않다

**같이 검토했던 대안**: 운동 앱 결과 화면을 **캡처해서 OCR** (이미 `lib/ocr.native.ts` 파이프라인이 있다). 권한도 필요 없고 안드로이드도 그대로 되지만 **경로 그림은 못 얻는다**. 건강 연동을 먼저 하기로 했으니 캡처는 보조 수단으로 남겨둔다.

**순서**: 스토어 상품 등록·출시가 먼저. 이 기능은 카테고리가 이미 있어서 새 상품 등록 없이 나중에 업데이트로 넣을 수 있다.
